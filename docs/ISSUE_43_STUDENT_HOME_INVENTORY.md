# جرد Issue #43 — الصفحة الرئيسية للطالب

## حدود الجرد

أُجري هذا الجرد على فرع الأساس `official/phase-07-student-home` قبل التنفيذ، ومن دون
الاتصال بالإنتاج أو تشغيل SQL أو migrations. لا يغيّر التنفيذ Push V2 أو PWA أو
service worker، ولا يتضمن أي خطوة نشر إلى Hostinger.

## تطبيق Android

- `app-student` هو نقطة التركيب ويملك جلسة الطالب وNavigation root.
- `feature-home` كان يجلب `GET /api/v1/student/home` ويعرض بيانات المنصة الفعلية،
  لكنه لم يكن يحتفظ بـ Home Snapshot؛ لذلك كان التشغيل بلا اتصال ينتهي بخطأ كامل.
- `core-network` يعرّف DTO مطابقًا لعقد Home المجمّع، و`core-datastore` يوفّر نمط
  DataStore المستخدم محليًا. لا توجد وحدات Native مستقلة للمواد أو الترتيب بعد،
  ولذلك لا يصح اختلاق محتواها أو بياناتها في هذه المهمة.

## Home API

المصدر الحالي يثبت أن Home endpoint للقراءة فقط، وأن هوية الطالب تستخرج من Bearer
token ولا يقبل التطبيق `student_id`. الاستجابة الواحدة تضم الطالب والنقاط والجواهر
والمستوى والسلسلة ونشاط اليوم والاشتراك والإشعارات وآخر نشاط والموجّه الدراسي.
يتولى Repository تدوير Access Token عبر refresh ثم يعيد الطلب مرة واحدة عند 401.

## قاعدة البيانات والمنصة القديمة

راجعت حزمة المصدر فقط في `server-hostinger/public_html/api/_student_home.php`.
القراءات مقيدة بالطالب المصادق عليه وتشمل `app_notifications`،
`student_last_activity`، `student_subject_state`، `subject_versions`، `subjects`
و`units`، ثم تستخدم دوال لوحة المنصة الموجودة للسلسلة والموجّه. لا ينشئ endpoint
خطة ولا يمر على الطلاب. لم يُشغّل أي استعلام أو ملف SQL على أي قاعدة بيانات.

## قرار التنفيذ

يُحفظ آخر رد ناجح ضمن مساحة التطبيق الخاصة بواسطة Preferences DataStore،
مع مالك snapshot ووقت حفظه وإصدار مخططها، ولا تُقبل بعد 24 ساعة. لا تُعاد snapshot لطالب آخر، وتُمسح صراحة عند تسجيل
الخروج. عند فشل الشبكة أو خطأ خدمة قابل للاسترداد تعرض الصفحة آخر بيانات حقيقية
مع تنبيه واضح؛ انتهاء الجلسة لا يستخدم cache ويعيد المستخدم إلى المصادقة.

تعمل القراءة بأسلوب cache-first: تعرض ViewModel النسخة الصالحة فورًا وتنفذ تحديث
Home API في الخلفية. أضيفت المؤشرات الأربعة والمواد والخبر/العرض إلى عقد الاستجابة،
ونُقل الموجّه إلى تبويب مستقل ضمن Navigation Compose ذي خمس وجهات typed.
