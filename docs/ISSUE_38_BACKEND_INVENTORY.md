# جرد التسجيل واسترداد الحساب والبيانات الأكاديمية — Issue #38

تاريخ الجرد: 2026-07-22. يصف هذا الملف **فقط** ما هو متتبع في نسخة المستودع
المحلية، ولا يفترض وجود مسارات أو جداول في بيئة الإنتاج.

## النتيجة التنفيذية

لا تحتوي حزمة `server-hostinger` الحالية على API لتسجيل طالب جديد، أو لاسترداد
الحساب، أو لقراءة القوائم الأكاديمية. لذلك لا يمكن تنفيذ إرسال التسجيل Native أو
إنشاء DTOs لقوائم مرجعية من دون اختراع عقد غير موجود، وهو محظور في هذه المرحلة.
يعرض تطبيق Android بدلًا من ذلك حالة صريحة بأن التسجيل غير متاح من التطبيق،
ومسار دعم يدوي لاسترداد الحساب، ولا يرسل بيانات ولا يوحي بإرسال رمز تحقق.

## المسارات المثبتة من الكود

الموجّه والملفات الفعلية تثبت المسارات الآتية فقط:

| الطريقة | المسار | الدليل المحلي |
|---|---|---|
| GET | `/api/v1/health` | `server-hostinger/public_html/api/v1/health.php` |
| POST | `/api/v1/auth/student/login` | `server-hostinger/public_html/api/v1/auth/student/login.php` |
| POST | `/api/v1/auth/refresh` | `server-hostinger/public_html/api/v1/auth/refresh.php` |
| POST | `/api/v1/auth/logout` | `server-hostinger/public_html/api/v1/auth/logout.php` |
| GET | `/api/v1/me` | `server-hostinger/public_html/api/v1/me.php` |
| GET | `/api/v1/student/home` | `server-hostinger/public_html/api/v1/student/home.php` |

لا يوجد ملف PHP أو توجيه للتسجيل، أو نسيان/إعادة تعيين كلمة المرور، أو المدن، أو
الصفوف، أو الأقسام/الشعب، أو المدارس، أو المناهج.

## منطق الحساب والحقول المثبتة

تسجيل الدخول يبحث في `app_users` باسم `username`، ويقرأ الحقول:
`id`, `role`, `full_name`, `username`, `password_hash`, `is_active`,
`manual_status`, `city_id`, `school_id`, `grade_id`, `avatar_path`,
`student_code`. يقبل فقط دور `student` وكلمة مرور متوافقة مع `password_verify`
وحسابًا فعالًا غير `suspended` أو `archived`.

لا يثبت الكود المحلي:

- بنية إنشاء صف في `app_users` أو قواعد الاسم والهاتف والتفرد.
- أسماء جداول المدن أو المدارس أو الصفوف أو الأقسام أو المناهج وأعمدتها.
- علاقة المدينة بالمدرسة، أو المدينة التي لا تتطلب مدرسة.
- قواعد إخفاء الأقسام الإدارية أو ربط نسخة المنهج.
- نص/روابط الشروط وسياسة الخصوصية.

وجود مفاتيح `city_id`, `school_id`, و`grade_id` في قراءة مستخدم موجود لا يكفي
لاستنتاج جداول مرجعية أو قيم صالحة للتسجيل.

## الاسترداد

لا توجد آلية استرداد أو OTP أو رمز تحقق في الحزمة المتتبعة. حفاظًا على عدم كشف
وجود الحساب، لا يطلب مسار الدعم اليدوي اسم مستخدم أو هاتفًا ولا يعرض نتيجة بحث.
يوجّه الطالب إلى إدارة/دعم المنصة عبر قناة الدعم المعتمدة لديه، من دون تثبيت رقم
هاتف أو رابط غير موجود في المستودع.

## قاعدة البيانات والأمان

ملف SQL الوحيد يعرّف جلسات API وأحداث المصادقة، ولا يعرّف التسجيل أو البيانات
الأكاديمية. لم يُشغّل هذا الملف أثناء الجرد. كما أن `_database.php` ينشئ مخطط
جلسات المصادقة وقت التشغيل؛ لم يُستدعَ محليًا ولم يحدث أي اتصال بالإنتاج.

## أثر الجرد على العقد

لم يتغير API الحقيقي، لذلك تُرك OpenAPI والـfixtures ومدقق العقد دون إضافة
مسارات تخمينية. استكمال التسجيل Native يتطلب أولًا إيداع كود الخادم الحقيقي
وعقده (بما يشمل idempotency والتحقق من العلاقات والتفرد وشكل نجاح الجلسة)، ثم
يمكن بناء الخطوات الثلاث والـDTOs والـcache والاختبارات عليه بأمان.
