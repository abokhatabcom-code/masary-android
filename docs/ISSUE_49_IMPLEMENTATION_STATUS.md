# حالة تنفيذ المرحلة العاشرة — Issue #49

**نقطة الأساس:** `aefbd7efdaf42e13387d63b0056f55f40ba00410`  
**فرع التنفيذ:** `phase-10-subject-page-implementation`

## الدفعة الحالية

- أضيف مسار قراءة آمن:
  `GET /api/v1/student/subject?subject_version_id={id}`
- يتحقق الخادم من أن المادة ضمن مواد الطالب المصادق قبل إعادة التفاصيل، ويستخدم استجابة 404 موحدة للمادة غير المرتبطة.
- أضيف عقد OpenAPI للمرحلة العاشرة وFixture واختبارات تمنع IDOR والكتابة وتحميل الأسئلة.
- أضيفت وحدة `feature-subject` المستقلة بRepository وCache متعدد المواد وViewModel وواجهة RTL.
- رُبطت وجهة `SubjectDetails(subjectVersionId)` مباشرة بـ`StudentSubjectRoute` بدل الشاشة المؤقتة المعتمدة على Home Snapshot.
- أُعيد ملف Android CI إلى نصه الأصلي، وحُذفت جميع أدوات الربط والجسور المؤقتة من الفرع.

## قرارات عدم الاختلاق

- نقاط المادة تعرض فقط عندما يتوفر `subject_xp` المؤكد.
- المستوى ونسبة التقدم يعادان كغير متاحين حتى تثبيت مصدر ومعادلة رسمية.
- وقت استعادة القلب لا يتحول إلى عد تنازلي من الحقل التاريخي دون إثبات دلالته الدقيقة.
- الوسائط وحالة الوصول التفصيلية لا تُخترع.
- آخر النشاط يعرض كمعلومة فقط؛ سجل `mode` الحالي لا يكفي لبناء عقد شاشة التهيئة بأمان من دون `activity_type` و`source` مؤكدين.
- مركز التدريب ظاهر كإجراء مملوك للصفحة لكنه غير مفعل حتى المرحلة الحادية عشرة.
- بطاقات الوحدات والدروس وقواعد فتحها مؤجلة للمرحلة الثانية عشرة، مع إبقاء موضعها داخل صفحة المادة.

## الحدود المحفوظة

- لا نشر إلى Hostinger.
- لا SQL أو migrations أو تعديل قاعدة بيانات الإنتاج.
- لا تعديل Push V2 أو PWA أو service worker.
- لا دمج في الفرع الرسمي قبل اكتمال بوابات الجودة واعتماد مالك المشروع.
